# Cisco CyberOps Associate Labs

## About This Repository

This repository documents my practical cybersecurity learning journey through Cisco CyberOps Associate labs and exercises.

My goal is to develop practical skills in cybersecurity operations, networking, security monitoring, threat detection, investigation, and troubleshooting.

Each lab will include its objectives, environment, procedures, technical explanations, observations, troubleshooting notes, and key lessons learned.

## Learning Objectives

- Develop practical cybersecurity operations skills.
- Understand networking and security concepts through hands-on exercises.
- Practise analysing system and network information.
- Document commands, findings, and troubleshooting processes.
- Build a structured portfolio of practical cybersecurity work.

## Lab Environment

- **Host operating system:** Linux Mint
- **Virtualization platform:** Oracle VirtualBox
- **Virtual machines:** Cisco CyberOps Workstation and Security Onion, as required by the labs.
- **Lab resources:** Cisco Networking Academy course materials.

The environment and tools used may vary depending on each exercise.

## Documentation Approach

Each lab will have its own directory containing a `README.md` report and an `evidence/` directory for relevant screenshots or other permitted evidence.

Reports will focus on what I actually performed, observed, learned, and verified.

## Responsible Learning

All exercises are performed for educational purposes in authorised lab environments. Sensitive information, passwords, virtual machine images, and restricted course materials will not be published in this repository.
